# 📚 LIBRA – Smart Library Management System

### Where Knowledge Meets Innovation

LIBRA is a web-based Smart Library Management System developed as a **team project** to simplify and digitize library operations.

## 🚀 Features

### Admin Module
- Admin Login and Dashboard
- Add, Edit and Archive Books
- Manage Book Issues and Returns
- Approve Book Requests
- Manage Student Accounts
- Manage Membership Requests
- View Library Reports and Statistics

### Student Module
- Student Registration and Login
- Student Dashboard
- Browse and Search Books
- Request Books
- View Book Activity
- Explore Membership Plans
- Request Membership
- View Membership History

## 🛠️ Technologies Used
- HTML
- CSS
- PHP
- MySQL

## 💻 Installation & Setup

1. Install XAMPP.
2. Start Apache and MySQL.
3. Download this repository.
4. Place the project folder inside `C:\xampp\htdocs\`.
5. Open phpMyAdmin.
6. Create a database named `library_system`.
7. Import `library_final_backup.sql`.
8. Check database settings in `config/db.php`.
9. Open `http://localhost/library_auto/` in your browser.
